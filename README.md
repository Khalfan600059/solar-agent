# Solar Agent — منصة إدارة الطاقة الشمسية

منصة رقمية متعددة الأدوار لإدارة مشاريع الطاقة الشمسية في عُمان، تابعة لشركة **Battery Fleet** —
تشمل حاسبة جدوى احترافية، ومسار طلب مترابط (العميل ← المهندس ← الاستشاري ← الشركة)،
ومنافسة عكسية مباشرة، ونظاماً مالياً، ولوحات تحكم لكل دور.

> ملف واحد مكتفٍ ذاتياً (`index.html`) — لا يحتاج خادماً ولا تنصيب أي شيء.

---

## التشغيل محلياً
افتح `index.html` مباشرةً في المتصفّح (Chrome / Edge). لا يلزم أي إعداد.

## المحتويات
| الملف | الوصف |
|------|-------|
| `index.html` | المنصة كاملة (HTML + CSS + JavaScript مضمّنة) |
| `دليل-النشر-والربط.md` | خطوات النشر على GitHub Pages والربط مع batteryom.om |
| `.gitignore` | استثناءات Git |

## التقنيات
- HTML5 / CSS3 / JavaScript (بدون إطار عمل)
- Chart.js و SheetJS (تُحمّل من CDN)
- واجهة عربية RTL + دعم الإنجليزية

## النشر السريع (GitHub Pages)
1. ارفع الملفات إلى مستودع GitHub.
2. Settings ← Pages ← Branch: `main` / root ← Save.
3. سيصبح الرابط: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

التفاصيل الكاملة والربط مع موقعك في: **`دليل-النشر-والربط.md`**

## الإصدارات
استخدم Git لإدارة النسخ:
```bash
git add -A
git commit -m "وصف التعديل"
git push
```
كل دفعة (push) تُحدِّث الموقع المنشور تلقائياً خلال دقيقة.
